Node.js 22.12 or later is now required

This package had no `engines` field before, so nothing was enforced. It now matches the rest of the Portable Text packages.

This only affects the machine that installs and builds, not the device the app runs on. If you build on Node.js 20, which reached end of life in April 2026, upgrade to 22.12 or later before taking this version.
